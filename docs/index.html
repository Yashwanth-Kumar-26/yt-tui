Why I built it

My HP laptop is four years old with 8 GB of RAM. Music on YouTube in a browser took 400 to 600 MB. I wanted the same music without the browser.

Install it

  1. Install the system players and thumbnail renderer first.

    # Ubuntu / Debian
sudo apt install mpv chafa

  2. Clone the repository and run its platform setup.

    git clone https://github.com/Yashwanth-Kumar-26/yt-tui.git
cd yt-tui
./setup.sh

  3. On Windows, use the repository's command script instead.

    setup.cmd

  4. Or install it as a global uv tool, then launch it.

    uv tool install .
yt-tui

Requires Python 3.10+. mpv handles playback and chafa is optional for thumbnail rendering.
